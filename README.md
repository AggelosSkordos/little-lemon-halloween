# Little Lemon — Halloween Homepage 🎃🍋

A Halloween-themed Little Lemon restaurant homepage created as part of Meta's **HTML and CSS in Depth** course.

## Project Overview

This project focuses on creating a visually engaging restaurant homepage using semantic HTML5 and CSS3.

The page includes a Halloween-themed promotional section, navigation bar, seasonal menu cards, and a structured footer.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Semantic HTML
- CSS transitions and pseudo-elements

## Features

- Semantic HTML structure
- Halloween-themed hero section
- Navigation bar
- Three seasonal menu cards
- CSS Grid layout
- Image-based promotional content
- Hover effects
- Static image fade effect
- Structured footer

## Future Improvements

- Add a fully responsive layout for mobile and tablet devices.
- Improve navigation behavior on smaller screens.
- Optimize image sizes for different screen resolutions.
